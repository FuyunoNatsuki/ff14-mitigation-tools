# Mitigation Planner

FINAL FANTASY XIV のレイド向けに、敵の攻撃に対する軽減の配置を計画し、各メンバーが受けるダメージと生存可否を予測するツールです。ブラウザだけで動き、インストールは要りません。手元で使うときは `build.ps1` で作る1ファイル版（`dist/MitigationPlanner.html`）を開いてください。

公開ページ: https://fuyunonatsuki.github.io/ff14-mitigation-tools/

## できること

- **ログの読み込み**：FF Logs のレポートURLを貼ると、戦闘ごとに敵の攻撃の元ダメージ（軽減前ダメージ）を読み込みます。公開ページでは「FF Logs でログイン」を押すだけで使えます（FF Logs のアカウントが必要です）。HTMLファイルを直接開いた場合は、FF Logs API のクライアントIDとシークレットを入力します。バリアで吸収されたヒットは、元ダメージのサンプルから除外します。
- **メンバー**：参加人数（標準は8人）と各メンバーのジョブを選び、最大HP・クリティカル・意思力・不屈・信仰・SS・物理防御・魔法防御を入力できます。空欄はジョブごとの標準値を使います。被ダメージの計算に使うのは最大HP・不屈・物理防御・魔法防御です（防御力は「防御力の軽減を入れる」をオンにしたときだけ）。
- **軽減タイムライン**：メンバーごとに、そのジョブの軽減をアイコンで配置します。行の並びはメンバーとジョブの軽減の順で固定され、バーを左右に動かしても入れ替わりません。バーの下の薄い線はリキャストを表します。
- **ヒール・バリアとHPの推移**：「ヒール・バリア」タブで回復・HoT・バリア・回復アップのスキルを配置すると、攻撃のダメージと合わせてメンバーごとのHPの推移を時刻順に計算し、タイムラインのメンバーの行にグラフで出します。回復量はメンバーに精神と武器の魔法性能を入れると回復計算式（f(回復魔法力)・f(意思力)・f(武器)・特性・f(不屈)／HoTはf(SS)・クリティカル）で、入れないときは威力×回復係数×意思力の簡易計算で出します（クリティカルは期待値も選べます）。レベルごとの定数は `data/job-data.js` の `MP_LEVEL` で変えられます（Lv100の回復魔法力の係数は未確認のため、Lv90の値を仮に入れています）。秘策の対象スキルはクリティカル確定、ニュートラルセクト中のアスペクト・ベネフィク／ヘリオス・コンジャンクションにはバリアを足します。平常時の回復（3秒ごとに最大HPの何%か）も指定できます。
- **元ダメージの上書き**：攻撃ごとに元ダメージを手入力でき、ログの値より優先して使います（ルームでは全員に共有されます）。
- **共有ルーム**：「共有ルームを作る」で `mitigation-planner.html?room=ルームID` の共有リンクを発行します。リンクを開いた人はアカウントなしで参加でき、編集はすぐに全員へ反映されます。ルームのリンクを知っている人は誰でも編集できるので、信頼できるメンバーにだけ渡してください。

## 数値を直すとき（`data/`）

パッチや装備に合わせて書き換えることが多いデータは、`data/` にまとめています。

- `data/job-data.js`：メンバーのステータスや最大HPが空欄のときに使う、ジョブごとの標準値。値はパッチ7.xの零式装備を想定した目安です。軽減アイコンを画像に差し替えたいときは、`MP_ACTION_ICONS` に軽減のIDと画像URLを書きます。
- `data/heals.js`：ヒール・バリアのスキルの一覧（威力・HoT・バリア・効果時間など）と、軽減スキルが持つ回復の効果。威力は7.xの目安です。
- `data/mitigations.js`：軽減スキルの一覧（軽減率・効果時間・リキャスト・使えるジョブ・アイコンの略称）。軽減の `id` は保存済みのプランで使っているので変えないでください。

## 被ダメージ計算機（`ff14-mitigation.html`）

素ダメージと軽減・バリアを選んで、タンク・ヒーラー・DPSそれぞれの被ダメージを計算する単発の計算機です。

## 注意

軽減率と効果時間はパッチ7.x（黄金のレガシー）時点の値です。パッチで変わることがあります。不屈の軽減はLv100の計算式（不屈420を基準）、防御力の軽減は `15 × 防御力 ÷ 2780 %`（Lv100）で計算しています。FF Logs の元ダメージに防御力の分がすでに含まれているかは確認できていないため、防御力の軽減は標準ではオフです。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `mitigation-planner.html` | Mitigation Planner の画面（HTMLの骨組み） |
| `css/planner.css` | 見た目（色・レイアウト） |
| `data/job-data.js` | ジョブごとの標準ステータス・最大HPとアイコンの差し替え設定 |
| `data/mitigations.js` | 軽減スキルの一覧 |
| `data/heals.js` | ヒール・バリアのスキルの一覧 |
| `js/constants.js` | ジョブと軽減の定数 |
| `js/state.js` | 画面全体の状態と小さな道具（保存・書式など） |
| `js/members.js` | メンバー、不屈・防御力による被ダメ倍率 |
| `js/fflogs.js` | FF Logs との通信（ログイン・ログの読み込み） |
| `js/fight.js` | ログから攻撃一覧を作る処理、保存用の形式、サンプル戦闘 |
| `js/calc.js` | 被ダメージの計算 |
| `js/hp.js` | HPの推移（ダメージ・回復・HoT・バリア）の計算 |
| `js/render.js` | 画面の描画（メンバー表・タイムライン・予測表） |
| `js/store-local.js` | このブラウザだけに保存する処理と、保存先の切り替え |
| `js/sync-room.js` | URLで共有するルーム（中継サーバー経由） |
| `worker/` | 共有ルームの中継サーバー（Cloudflare Workers）。公開ページには含めない |
| `js/sync-claude.js` | claude.ai のページとして開いたときの共有 |
| `js/peers.js` | 同時に開いている人の表示 |
| `js/events.js` | ボタンや入力などの操作 |
| `js/main.js` | 起動処理 |
| `ff14-mitigation.html` | 被ダメージ計算機 |
| `index.html` | プランナーへ移動するだけのページ（GitHub Pages のトップ用） |
| `fflogs-planner.html` | 旧URLで共有されたリンクを新しいページへ移すためのページ |
| `.github/workflows/pages.yml` | GitHub Pages への公開（読み込みへのバージョン付け） |
| `build.ps1` | 全部を1つのHTMLにまとめた版（`dist/MitigationPlanner.html` と claude.ai 用の `online/index.html`）を作るスクリプト |

`js/` のファイルは、`mitigation-planner.html` に書いた `<script>` の順に読み込まれます。新しいファイルを足すときは、使う側より前に読み込まれるように並べてください。

## 公開のしくみ

main に push すると、GitHub Actions（`.github/workflows/pages.yml`）が GitHub Pages に公開します。そのとき `mitigation-planner.html` の `css/`・`js/`・`data/` の読み込みに `?v=コミットID` を付けるので、更新後にブラウザに古い CSS や JS が残っていても、新しいものが読み込まれます。手元のファイルには何も付けなくてかまいません。

共有ルームのデータは、中継サーバー（`worker/`、Cloudflare Workers）を通して保存します。ブラウザがつなぐのは中継サーバーだけで、データベースのURLと鍵は中継サーバーの Secrets にだけ置いています。中継サーバーを更新するときは、`worker/` で `npx wrangler deploy` を実行してください。
